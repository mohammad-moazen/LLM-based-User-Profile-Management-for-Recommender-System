## v4 safeguard
The LLM still performs the paper-derived Profile Updater selection step, but profile text is never generated by the updater. The model returns same-category entry IDs only.

The deterministic v4 guard then enforces an information-preserving rule:
1. unrelated unique omissions are restored;
2. an overlap deletion is allowed only when a retained same-category entry strictly dominates the omitted entry in information content under the conservative lexical rule;
3. if the model keeps a shorter overlap and omits a richer one, the richer entry is restored;
4. a second deterministic pass removes the dominated shorter representative;
5. exact duplicates collapse safely.

This guard is a documented reproduction engineering choice because the PURE paper does not publish its exact Profile Updater schema or post-processing/conflict-resolution implementation.

## Removal audit
Exactly one final unique overlap removal occurred in the 15-update pilot.

Removed shorter evidence:
`It has a lot of charm and it is challenging enough.`

Retained richer evidence:
`Beautiful game. It has a lot of charm and it is challenging enough.`

This is the desired direction: the retained sentence contains the full shorter statement and adds the additional information `Beautiful game.` No unrelated unique evidence was finally deleted.

## Interpretation
Pilot v4 resolves the concrete failure modes observed in v1-v3:
- no arbitrary unique-evidence deletion can propagate through the deterministic guard;
- no text-copy rewrite can occur because the model returns IDs only;
- overlap deletion is directional and preserves the richer representative.

The 51 guard restorations show that the local derivative model still frequently requests deletions that the conservative project policy does not consider mechanically safe. This is not a technical failure; it demonstrates that the deterministic guard is materially affecting the final profile.

Pilot v4 is therefore **accepted for the full chronological Phase 4 run**, but Phase 4 is not frozen solely from this pilot. The full run must verify all 134 required profile updates, prefix contiguity, prompt-size behavior under the 8192 context setting, and actual profile compaction across all required prefixes.
